# 🎫 Ticketing System (Laravel + Vue.js)

Repositori ini berisi proyek *full-stack* sistem manajemen tiket (*ticketing system*) yang dibangun secara *end-to-end* menggunakan versi terbaru dari **Laravel** dan **Vue.js**[cite: 1]. 

Proyek ini saya kembangkan sebagai bagian dari dokumentasi perjalanan belajar ( *learning by doing* ) untuk memperdalam pemahaman mengenai arsitektur web modern, pemisahan *backend/frontend*, dan manajemen pangkalan data.

## 🚀 Tech Stack
- **Backend:** Laravel 12 (RESTful API)
- **Frontend:** Vue.js (Komponen Antarmuka)
- **Database:** MySQL
- **Styling:** Tailwind CSS

## 💡 Pembelajaran Utama (Key Learnings)
Melalui proyek ini, saya berhasil mempelajari dan mengimplementasikan beberapa konsep inti, antara lain:
- **Perancangan Basis Data:** Merancang struktur tabel dan relasi pangkalan data untuk sistem tiket[cite: 1].
- **Backend Engineering:** Membangun RESTful API menggunakan kerangka kerja Laravel[cite: 1].
- **Frontend Integration:** Menghubungkan *endpoint* API dengan antarmuka interaktif menggunakan komponen-komponen Vue.js[cite: 1].
- **State & Transaction Management:** Mengelola status transaksi dan alur pembelian tiket dari sisi klien hingga peladen[cite: 1].
